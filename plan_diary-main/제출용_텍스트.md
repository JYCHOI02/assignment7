# ALEPH Studio 최종 제출용 텍스트 (T07 카드 5)

아래 내용을 ALEPH Studio 과제 제출 폼에 그대로 복사하여 입력하시면 됩니다.

---

### 재현·통과 확인 4가지

**어디로 가나요:**
[http://127.0.0.1:5000 또는 배포된 터널 URL (예: https://bracelets-adipex-louisville-notebook.trycloudflare.com)]

**무엇을 하나요:**
1) 비로그인 상태로 메인 화면(`/`) 또는 데이터 API(`/api/plans`)에 진입하여 `/login`으로 강제 이동되거나 401 Unauthorized로 차단되는지 확인합니다.
2) `jychoi` 계정으로 로그인 후 상단 [SEE] 탭에서 서로 다른 5일치 운동하기 관찰 기록(2026-09-24 ~ 2026-09-28, 어제까지 5일치, 3일차 50분 뽀모도로 규칙 변경)과 합계(계획 480분, 실행 412분, 달성률 85.8%) 및 산술평균(85.4%)이 손계산과 정확히 일치하는지 확인하고, 상단 [📥 전체 자료 파일로 내보내기 (JSON)] 버튼으로 단일 백업 파일이 다운로드되는지 테스트합니다.
3) 우측 상단 [로그아웃] 버튼 클릭 후 브라우저 '뒤로 가기' 또는 이전 세션으로 데이터 API 재호출 시 즉시 접근이 차단되는지 확인합니다.
4) 제출 문서(`인증구현설명서.md` 또는 과제 보고서)에서 ① 무엇으로 붙였나부터 ⑥ 아직 못 막은 것까지 6개 번호 항목과 마스킹 처리(`eyJhb...[생략]`, `****`)를 확인합니다.

**무엇이 보이면 통과인가요:**
- 비인가 사용자의 접근 거절(401/403) 및 정상 로그인 유저의 5일치 관찰 통계(합계·평균 0 오차 일치), 단일 JSON 파일 내보내기 및 탈퇴 시 영구 삭제 안내 문구가 모두 정상 동작하고, 모든 증빙에서 비밀번호와 토큰이 안전하게 마스킹된 것이 보이면 통과입니다.

**안 될 때:**
- 브라우저 쿠키/로컬 스토리지 캐시 초기화 후 재시도하거나, 시크릿 창(InPrivate 모드)에서 재진입하여 테스트합니다.

### AI와 내 판단 3줄

**AI에게 맡긴 일:**
Flask `@login_required` 인증 가드 라우팅 데코레이터 및 5일치 관찰 통계(결측치 0 처리, Math.round 소수점 첫째 자리 집계) 보일러플레이트 코드 작성.

**내가 직접 판단한 일:**
2일차 실천 후 3일차부터 1회 90분 고강도 단일 블록을 50분 뽀모도로 세분화(웨이트 35분+유산소 15분, 10분 휴식 2세트) 방식으로 변경한 의사결정 및 세션 만료 30분 정책·비밀번호 변경 시 이전 세션 일괄 무효화 정책 결정.

**AI 말을 안 들은 일:**
AI가 제안한 서드파티 외부 클라우드 인증(Firebase/Supabase SaaS 의존) 대신, SQLite 로컬 DB와 긴밀히 결합되어 외부 종속성이 없는 자체 완결형 세션(Flask-Login + PBKDF2) 및 WebAuthn 생체인식 아키텍처를 고수한 결정.

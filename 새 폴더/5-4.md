### 재현·통과 확인 4가지
어디로 가나요: [배포된 GitHub Pages 결과물 URL]
무엇을 하나요:
1) 비로그인 상태로 진입하여 로그인 화면으로 강제 이동되는지 확인
2) 로그인 후 5일치 다이어리 통계 및 데이터 내보내기(다운로드) 테스트
3) 로그아웃 후 이전 URL로 재진입 시 다시 차단되는지 확인
무엇이 보이면 통과인가요:
- 비인가 사용자의 접근 거절 및 정상 로그인 유저의 5일치 통계(합계·평균 일치), 파일 내보내기 정상 동작
안 될 때:
- 로컬 스토리지 캐시 초기화 후 재시도 / 시크릿 창에서 테스트 안내
